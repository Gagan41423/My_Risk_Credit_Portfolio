# My_Risk_Credit_Portfolio
In this project we Build a complete credit risk model and decision based on it from scratch using python and SQL Data have almost over half a million rows for Taked from kaggle Lending dataset 2008 to 2015 which we have to preprocess and clean it into a paraquet because git can't take 300mb file we uploaded direct paraquet files after cleaning and preprocessing rows and columns and load in there for our furthur analysis which each stage we make it more clean shown as v1, v2 Parquet files.
Then we use that files which help us to build model and do in depth analysis from basic to advance for credit risk with woe, iv, AUC, gini and later for scroring each variable and give a final decision based on our model prediction.
